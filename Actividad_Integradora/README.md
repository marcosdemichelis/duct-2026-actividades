# Analizador de Frecuencias de Palabras

Herramienta en Python para analizar un .txt, segmentar las palabras, 
contabilizarlas y generar un gráfico de barras con las 10 más frecuentes.

## Requisitos

- Python 3.10 o superior
- pip

## Instalación

```bash
git clone falta link
cd Actividad_Integradora
python -m venv venv
source venv/bin/activate    # en Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Uso

### Ejecutar el análisis principal y generar grafico_frecuencias.png
```bash
python analizador.py
```

### Ejecutar las pruebas automáticas
```bash
pytest
```
